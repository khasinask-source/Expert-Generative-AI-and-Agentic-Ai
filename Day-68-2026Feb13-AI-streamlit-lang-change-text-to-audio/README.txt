# NLP Applications – Translation & Speech Systems

This repository demonstrates practical Natural Language Processing (NLP) applications for language translation, speech synthesis, and interactive text processing using Python and Streamlit.

## Streamlit Framework
Streamlit is used to build interactive web-based NLP applications with minimal frontend code.

## Language Translation
Text input is translated between languages using machine translation libraries.

## mtranslate Library
mtranslate performs lightweight language translation using online translation services.

## deep_translator Library
deep_translator provides reliable multilingual translation with better stability than legacy translators.

## Language Dataset
A language mapping file connects human-readable language names to standardized ISO codes.

## Language Selection Interface
Users select target languages dynamically via sidebar or multiselect components.

## Language Detection
Automatic language detection identifies the source language from input text.

## langdetect Library
langdetect predicts the most probable language based on text patterns.

## Text Normalization
Regular expressions remove unwanted characters to prepare clean text.

## Lowercasing
Text is converted to lowercase to ensure consistent processing.

## Tokenization
Text is split into smaller units for linguistic analysis and filtering.

## Stopwords Removal
Common words are filtered to retain semantically meaningful content.

## Text-to-Speech (gTTS)
gTTS converts text into spoken audio using Google’s speech synthesis engine.

## Audio Generation
Generated speech is saved as MP3 files for playback and download.

## Streamlit Audio Player
Audio is rendered directly in the web interface using Streamlit’s media components.

## Temporary File Handling
Audio files are created and safely deleted to manage storage efficiently.

## pyttsx3 Engine
pyttsx3 performs offline text-to-speech conversion without internet dependency.

## Speech Rate Control
Voice speed is adjusted to improve listening clarity.

## Voice Selection
Different system voices (male/female) are selected programmatically.

## Volume Adjustment
Speech loudness is configured for optimal audio output.

## Word Cloud Visualization
Frequently occurring words are visualized using graphical word clouds.

## WordCloud Library
WordCloud generates visual representations based on word frequency.

## Language Filtering
Word clouds focus on valid dictionary words to avoid noise.

## Background Styling
Custom CSS is injected to enhance Streamlit UI appearance.

## NLP Processing Pipeline
Text → Cleaning → Detection → Translation → Speech → Visualization.

## Multilingual Processing
Applications support multiple languages for translation and speech synthesis.

## Practical Learning Outcome
This project builds intuition for real-world NLP interfaces, language translation systems, and speech-based AI applications.
